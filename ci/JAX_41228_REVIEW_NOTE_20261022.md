## Reply to the performance concern and test-consolidation request

The Poisson hot-path change is now supported by a **source-matched,
deterministic old-vs-new sampler comparison**, including a disjoint-seed
empirical distribution validation.

The benchmark reconstructs the original production rejection sampler from
the exact current `_poisson_rejection` source AST, restoring just the original
hoisted `log_lam` and `t = -lam + k * log_lam - lax_special.lgamma(k + 1)`
acceptance score. This controls for loop structure, input keys and backend.
JIT compilation is excluded from timings; each JIT call is synchronized.

### Strongest result: distributional correctness

At `lam = 1e8`, 12 held-out seeds (distinct from 8 pilot seeds) with 8192
samples per seed and method yielded:

| | Original sampler | Stable patch | Theoretical target |
|---|---:|---:|---:|
| Sample variance / lambda | **1.75308** | **1.00682** | 1.00000 |
| Standardized normal-approx. KS | 0.02810 | 0.00285 | As small as possible |

The old sampler's reported per-seed-block variance-ratio SE was 0.00692,
the stable patch's 0.00422. The result replicates the pilot (1.72197 vs
1.00101) and is output by the **actual source-derived compiled sampling
function**, not a proxy logpdf-only calculation.

Other fixed holdout lambda conditions (original vs stable variance/lambda):
`1e6`: 1.04287 vs 1.00694; `1e7`: 0.93491 vs 1.00670.
The normal-KS value uses a large-lambda asymptotic normal approximation; it
is not an exact discrete Poisson goodness-of-fit p-value.

### Runtime: positive but not uniformly guaranteed

15 paired, interleaved CPU JIT timings on Ubuntu/Windows generally show
similar or shorter patched execution times across lambda 10 and 1000.
At lambda 1e8, size 8192, the patched/original ratio ranged from about
0.93 to 1.43 depending on OS/run; therefore **no unconditional performance
improvement or no-regression claim** is warranted. No real GPU benchmark
has been performed. The correctness gain is much more robustly demonstrated
than the runtime gain.
